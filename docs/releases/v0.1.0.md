# Bountarr v0.1.0

Initial public release of Bountarr, a LAN-first household grab dashboard for Radarr and Sonarr.

## Highlights

- Search movies and series across Radarr and Sonarr, with optional Plex context.
- Start managed grabs with language, subtitle, season, and quality profile choices.
- Track Bountarr-managed acquisition jobs alongside live Arr queue entries.
- Validate completed grabs against preferred audio and subtitle expectations.
- Retry failed or invalid releases automatically when viable alternatives exist.
- Use manual release tools to inspect candidates and choose direct or Arr-rejection override releases.
- Review recent download checks, runtime health, storage, logs, and local acquisition database state from the UI.
- Receive local browser notifications for grab outcomes and audit warnings.

## Operations

- Requires Node.js 22 or newer.
- Configure Radarr and/or Sonarr through `.env`.
- Plex is optional.
- Build and run with:

```powershell
npm run build
npm run start
```

- PM2 remains optional through `ecosystem.config.cjs`.

## Security

Bountarr has no built-in authentication. Run it only on a trusted LAN or behind a VPN or authenticated reverse proxy. Do not expose it directly to the public internet.

Keep API keys, Plex tokens, logs, runtime data, and real live-wire media titles out of tracked files.
